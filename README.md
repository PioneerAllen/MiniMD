# MiniMD

一款轻巧简洁的 Mac Markdown 阅读与编辑器。

使用 Swift 和 AppKit 构建窗口与编辑器，通过系统 WebKit 渲染 Markdown。支持本地图片、数学公式和 Mermaid 图表，适合快速阅读文档，也能切换到编辑或分栏继续写作。

## 下载与安装

从本仓库的 Releases 下载 DMG，打开后将 **MiniMD.app** 拖入 **Applications**。

| 项目 | 当前版本 |
| --- | --- |
| 版本 | 0.1.0 |
| 安装包 | MiniMD-0.1.0-arm64.dmg |
| DMG 大小 | 1.42 MB |
| 应用文件合计 | 4.18 MB |
| 处理器 | Apple Silicon（M 系列） |
| 系统要求 | macOS 13 或更新版本 |
| 液态玻璃工具栏 | macOS 26 或更新版本 |

体积以当前 arm64 Release 构建计，MB 按 1,000,000 字节计算。Finder 显示的磁盘占用可能略有不同。

当前安装包采用本地临时签名，尚未经过 Apple 公证。首次打开时，macOS 可能要求确认应用来源。

## 功能

- **预览、编辑与分栏**。已有文档默认进入预览，新建文档直接编辑。分栏左侧预览、右侧编辑，中间分隔线可拖动调整宽度。
- **原生磨砂窗口**。跟随系统浅色与深色外观，液态玻璃工具栏可在设置里切换。全屏阅读使用随外观切换的黑色或白色背景。
- **多文档标签页**。新建和打开的文档默认进入标签页，支持拖出成为独立窗口，或通过「窗口 → 合并所有窗口」合并。
- **离线排版**。支持标题、列表、表格、任务清单、代码块、本地图片、KaTeX 数学公式和 Mermaid 图表，渲染资源随应用打包。
- **交互任务清单**。可在预览里勾选任务，修改会写回 Markdown 源码。
- **文档内查找**。预览可以搜索渲染后的正文，编辑区使用 macOS 原生查找和替换。
- **阅读宽度**。在「显示 → 预览宽度」选择标准宽度或 60%、75%、90%、100%。
- **本地文件操作**。支持 Finder 打开、拖入文档、保存和自动保存。外部文件更新后，无未保存修改时会自动刷新。
- **默认打开方式**。在「MiniMD → 设置」中可将 MiniMD 设为 `.md` 和 `.markdown` 的默认打开应用。

## 使用示例

本地图片路径以 Markdown 文件所在目录为基准，也支持应用能够读取的绝对路径。

~~~markdown
![示意图](./images/example.png)
~~~

行内公式使用一对美元符号，并保持在同一行。独立公式使用双美元符号。

~~~markdown
行内公式 $E = mc^2$。

$$
\int_0^1 x^2\,dx = \frac{1}{3}
$$
~~~

图表使用标记为 `mermaid` 的代码块。

~~~markdown
```mermaid
flowchart LR
    A[打开文档] --> B[阅读]
    B --> C[编辑与保存]
```
~~~

## 快捷键

| 快捷键 | 操作 |
| --- | --- |
| ⌘N | 新建文档 |
| ⌘O | 打开文档 |
| ⌘S | 保存 |
| ⌘W | 关闭当前文档 |
| ⌘1 | 预览 |
| ⌘2 | 编辑 |
| ⌘3 | 分栏 |
| ⌘F | 查找 |
| ⌘G | 查找下一个 |
| ⇧⌘G | 查找上一个 |
| ⌘, | 设置 |

预览模式搜索渲染后的正文。分栏时先点击需要查找的区域，再打开查找。「查找并替换」修改 Markdown 源码。


## 预览资源与边界

- Markdown 解析使用 markdown-it 14.1.1，数学公式使用 KaTeX 0.16.45，图表使用 Mermaid 11.14.0。相应许可证包含在应用资源中。
- 文档支持 UTF-8 和带 BOM 的 UTF-16 编码。
- 预览加载本地图片，单张图片的读取上限为 32 MiB。
- 原始 HTML 按文本处理，Mermaid 文档内的配置指令不启用。
- 同一窗口中的后台标签可释放预览资源，切回时重新渲染。实际内存使用与文档内容、图片及图表数量有关。
